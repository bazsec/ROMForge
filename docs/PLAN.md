# Implementation milestones

1. **Foundation — initial slice complete.** Rust workspace, payload ABI, development packager, headless Libretro memory host, original synthetic test ROM generator, real Zelda loading test on Apple Silicon. Complete the host contract and pinned native build automation next.
2. **Playable SNES / Windows POC — in progress.** SDL3 pixels/audio, AV timing, keyboard/gamepad input and SRAM are implemented and the macOS playback preview is verified; prove static core + SDL + CRT linkage on Windows x64. Package a user ROM into one unsigned `.exe`; test on a clean Windows machine without an emulator or redistributable installation. No splash, setup, or console window in the release template. Keep a separate diagnostic runner for development.
3. **F1 menu — macOS preview implemented.** Exactly five entries, paused/darkened background, remappable keyboard/controller buttons and axes, five validated state slots, scanlines off by default, fullscreen on, persistent settings. Built-in SDL pixel font adds no font asset/dependency. A wgpu/librashader comparison submenu now offers the actual Lottes, Guest Advanced and Royale CRT presets plus Off. Native state restore and keyboard menu checks pass; the user confirmed Bluetooth DualSense response with the window focused. Broader controllers/platforms remain to validate.
4. **macOS generation — Apple Silicon preview available.** Native game bundles include resources, core, static SDL runtime and persistent saves. Local ad-hoc signing, dependency inspection, launch and rendering checks pass. Intel templates, Developer ID signing/notarization and clean-machine Gatekeeper validation remain pending.
5. **Builder GUI and batches.** Rust desktop GUI over a platform-independent packaging service; input/output pickers, Windows/macOS/both selection, bounded worker queue, structured progress/errors, cancellation, incremental fingerprints, safe output naming, invalid-ROM handling. Selection can use native dialogs; An egui/eframe preview now provides folder pickers, a SNES list, and single-ROM background test/package jobs; production batch processing remains pending.
6. **Console expansion.** Add pinned core adapters/capability manifests and synthetic/homebrew tests for NES, GB/GBC, GBA and Genesis; validate licensing and accuracy before shipping each.
7. **Optimization.** Benchmark size, throughput and gameplay performance; strip and tune templates without compromising accuracy. Maintain clean-machine and per-architecture compatibility gates.

Release gates: true single-executable Windows dependency audit; macOS bundle dependency/signature audit; pinned source/license inventory; representative user-authorized game compatibility; persistent saves; ABI/payload failure tests. These have not passed yet.
